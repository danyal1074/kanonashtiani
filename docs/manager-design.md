# طراحی پنل مدیر
سبک: زمینه آبی روشن، منوی سرمه‌ای، کارت‌های برجسته و آیکون‌های سه‌بعدی.
فایل‌های تازه: public/css/manager.css، public/js/manager-ui.js، public/js/manager-icons.js.
آیکون‌ها با imagegen تولید شده‌اند؛ شیت icons.webp شامل ۱۶ نماد در شبکه ۴×۴ است.
campus.webp فقط در سربرگ خانه مدیر استفاده می‌شود.
تمام ۱۸ مسیر فعلی مدیر حفظ شده‌اند؛ اعداد کارت‌ها، جدول‌ها و نمودارها از APIهای قبلی می‌آیند.
سبک به body.manager-ui محدود است و در صفحه ورود یا نقش‌های دیگر فعال نمی‌شود.
خانه مدیر همه دسترسی‌های واقعی را نشان می‌دهد؛ گزینه‌هایی که در رفرنس هستند ولی API ندارند به صورت نمایشی اضافه نشده‌اند.

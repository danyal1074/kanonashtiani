# اتصال پنل به «کلاس آنلاین کانون»

قرارداد کامل: `docs/KANOON_PANEL_INTEGRATION.md` در مخزن کلاس آنلاین.

## تنظیمات (فایل `.env` یا محیط سرور؛ هرگز commit نشود)
| متغیر | توضیح |
|---|---|
| `CLASSROOM_API` | مثلاً `https://class.<دامنه>/api/v1` — بدون آن قابلیت خاموش است |
| `KANOON_PANEL_SECRET` | راز مشترک، حداقل ۳۲ نویسه (همان مقدار سمت کلاس آنلاین) |
| `CLASSROOM_TIMEOUT_MS` | اختیاری، پیش‌فرض ۸۰۰۰ |

## اجزا
- `server/classroom.js` — کلاینت امضاشدهٔ HMAC، همگام‌سازی، فهرست کلاس‌ها، بلیت ورود.
- `GET /api/student/online-classes` و `POST /api/student/online-classes/:classId/join` (فقط نقش دانش‌آموز؛ شناسه از نشست).
- همگام‌سازی خودکار هنگام ایجاد/ویرایش/ثبت‌نام گروهی/جابه‌جایی دانش‌آموز؛ همگام‌سازی کامل دستی یا دوره‌ای: `npm run sync:classroom` (`-- --dry-run` برای شمارش).
- نمایش: بخش «کلاس‌های آنلاین من» در صفحهٔ «کلاس آنلاین» دانش‌آموز.
- تست: `npm run test:classroom` (سرور ساختگی با اعتبارسنجی همان امضا).

# معماری بانک سؤالات و موتور آزمون رشد نخبه

## ۱. اصول طراحی
- **بدون وابستگی به API هوش مصنوعی:** تمام تولید، انتخاب، اعتبارسنجی و تصحیح آزمون‌ها با الگوریتم‌های داخلی بک‌اند انجام می‌شود.
- **یکپارچگی با ساختار فعلی رشد:** استفاده از `node:sqlite`، سیستم احراز هویت کوکی/توکن، جداول `users`, `centers`, `classes`, `students`, `teacher_classes` و کتب درسی موجود.
- **جداسازی کامل مدارس (Multi-tenancy):** هر سؤال به `center_id` یا کتاب استاندارد متصل است؛ معلم فقط در محدوده پایه و درس مجاز خود دسترسی دارد و مدیر کل مدرسه بر بانک مدرسه نظارت می‌کند.
- **امنیت پاسخنامه:** پاسخ صحیح (`answer_json`) و توضیح پاسخ (`explanation`) در جدول `questions` نگهداری شده و در زمان برگزاری آزمون هرگز به فرانت‌اند دانش‌آموز ارسال نمی‌شود.

## ۲. سلسله‌مراتب کتب درسی
```text
پایه تحصیلی (grade: 4..9)
  └── کتاب درسی (textbooks: id, book_code, title, subject_key, grade, cover_url, published)
       └── نسخه و سال چاپ (textbook_editions: edition_label, pub_year, pdf_path, printed_pages, pdf_offset)
            └── فصل (textbook_chapters: number, title, printed_start..printed_end, pdf_start)
                 └── درس (textbook_lessons: number, title, printed_start..printed_end)
                      └── صفحه (textbook_pages: printed_page, pdf_page, excluded, exclude_reason)
                           └── سؤالات مرتبط (questions + question_sources)
```

## ۳. چرخهٔ حیات سؤال و آزمون
1. **ورود سؤال:** دستی در ویرایشگر معلم یا گروهی از طریق Wizard نه‌مرحله‌ای (`ZIP` / `JSON` / `XLSX`).
2. **وضعیت‌ها:** `draft` → `pending_review` → `approved` → `published` (یا `rejected` / `archived`).
3. **ساخت آزمون:**
   - **تمرین آزاد دانش‌آموز:** انتخاب کتاب، محدوده (کل کتاب/فصل/درس/بازه صفحه)، تعداد، سطح دشواری (آسان/متوسط/سخت/ترکیبی با نسبت پیش‌فرض ۳۰/۵۰/۲۰ قابل تنظیم توسط مدیر).
   - **آزمون رسمی معلم:** انتخاب دستی سؤالات یا انتخاب خودکار از بانک + تاریخ شروع/پایان شمسی + تصحیح تشریحی مبتنی بر بارم.
4. **تصحیح و کارنامه:** تصحیح خودکار سرور برای ۱۰ نوع عینی + نرمال‌سازی متن فارسی/عربی/اعداد؛ تفکیک نمره موقت و رسمی برای تشریحی؛ به‌روزرسانی خودکار جدول `student_page_performance`.

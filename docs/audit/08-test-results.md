# ۰۸ — نتایج آزمون‌های خودکار (Test Results)

تمامی آزمون‌های زیر پس از آخرین تغییرات کد اجرا شده و خروجی واقعی آن‌ها ثبت شده است:

| آزمون | دستور اجرا | نتیجه | تعداد بررسی‌ها | توضیح |
|---|---|---|---|---|
| **تست دودی جامع سامانه** | `npm run smoke` | **پاس (۰ خطا)** | ۲۰۰ بررسی موفق | ورود همه نقش‌ها، ماتریس دسترسی، قفل پنل، آزمون، پرداخت، حسابداری، معلم، مدیر، دانش‌آموز، کلاس‌ها |
| **تست رگرسیون ممیزی و امنیت** | `node scripts/test-audit-repairs.mjs` | **پاس (۰ خطا)** | ۲۵ بررسی موفق | مسدودسازی معلم غیرمشاور (۴۰۳)، فیلتر پایه مشاور، معلم-مشاور ↔ دانش‌آموز، اکسل `.xlsx`، مصوبات جلسات، IDOR بانک سؤال |
| **تست پنل مشاور** | `node scripts/test-counselor.mjs` | **پاس (۰ خطا)** | ۶۱ بررسی موفق | مهاجرت و حفظ داده، جلسات، برنامه‌های هفتگی، یادداشت‌های خصوصی، جداسازی کانون‌ها |
| **تست مهاجرت دیتابیس** | `node scripts/test-migrations.mjs` | **پاس (۰ خطا)** | ۳ سناریو کامل | دیتابیس خالی، دیتابیس پشتیبان، رول‌بک تراکنش |
| **تست بانک سؤالات** | `node scripts/test-question-bank.mjs` | **پاس (۰ خطا)** | ۲۷ بررسی موفق | ZIP/XLSX/SVG، اعتبارسنجی، امنیت نقش و پایه، ساخت و تصحیح آزمون |
| **تست کتب درسی** | `node scripts/test-textbooks.mjs` | **پاس (۰ خطا)** | کامل | مجوز پایه/درس، صفحه معتبر، JPG/PDF خصوصی |
| **تست تمرین صفحه کتاب** | `node scripts/test-textbook-exercises.mjs` | **پاس (۰ خطا)** | کامل | تولید، کش هم‌زمان، تصحیح سرور، بودجه AI موک |
| **تست کلاس آنلاین و پیام‌رسان و ظاهر** | `test-classroom.mjs`, `test-messenger.mjs`, `test-teacher-look.mjs` | **پاس (۰ خطا)** | کامل | همگام‌سازی، رسید خواندن پیام، تغییر ظاهر معلم |
| **بررسی نحوی کل JS فرانت‌اند** | `node --check public/js/*.js` | **پاس (۰ خطا)** | همه فایل‌ها | بدون خطای نحوی یا import شکسته |
| **تست عکس پروفایل (VM)** | `node scripts/test-profile-photo.mjs` | **خطای ابزار** | — | نیازمند `--experimental-vm-modules` در Node ۲۴ |

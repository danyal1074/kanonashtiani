# فهرست اجزای قابل استفاده مجدد (Component Inventory)

**تاریخ:** ۱۴۰۵/۰۹/۰۶ (2026-11-27)

| دسته | کامپوننت / کلاس | وضعیت و استاندارد جدید |
|---|---|---|
| **دکمه‌ها** | `.btn`, `.btn.ghost`, `.btn.soft`, `.btn.red`, `.btn.green`, `.btn.accent`, `.btn.sm`, `.btn.lg`, `.icon-btn` | ارتفاع یکنواخت (`40px` دسکتاپ، `44px` موبایل)، افکت Press نرم (`scale(.98)`), حذف گرادیانت‌های شلوغ، اسپینر تمیز به‌جای ایموجی در `busy()` |
| **فرم‌ها** | `.field`, `.input`, `select.input`, `textarea.input`, `.date-field`, `.check`, `.chips`, `.chip`, `.seg`, `.field-error` | فوکوس یکنواخت با حلقه فیروزه‌ای نرم، تراز RTL/LTR خودکار، نمایش واضح خطای اعتبارسنجی |
| **کارت‌ها** | `.card`, `.card.flat`, `.card-title`, `.kpi-card`, `.ib` | حاشیه تمیز `1px`، سایه ملایم، هاور هدفمند برای کارت‌های قابل کلیک (`translateY(-2px)`) |
| **جداول** | `.table-wrap`, `table.table`, `.co-table` | سربرگ چسبان روشن، تراز عددی `tnum`، هاور نرم ردیف، اسکرول افقی تمیز با سایه راهنما در موبایل |
| **نشان‌ها و وضعیت** | `.badge` (`.green`, `.red`, `.orange`, `.blue`, `.gray`), `.progress`, `.countdown` | رنگ‌های ملایم با کنتراست استاندارد و خوانا |
| **پوسته و ناوبری** | `.sidebar`, `.topbar`, `.mobile-head`, `.bottom-nav`, `.me-chip`, `.imp-bar` | ساختار یکپارچه روشن در همه نقش‌ها، نشانگر فعال راست‌به‌چپ تمیز، بسته شدن خودکار کشو با Escape و تغییر اندازه |
| **بازخورد و پنجره‌ها** | `.modal-back`, `.modal`, `.toasts`, `.toast`, `.empty`, `.spinner`, `.skeleton` | انیمیشن ورود/خروج نرم، تله فوکوس کیبورد، حالت خالی با آیکون خطی و دعوت به اقدام شفاف |
| **نمودارها** | `barChart`, `lineChart`, `donut`, `ring` | پالت رنگ هماهنگ با برند، فونت فارسی `Vazirmatn` و اعداد `tnum` |

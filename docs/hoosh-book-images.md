# تصاویر استودیوی هوش کمپلکس

مسیر اصلی صفحات: ROSHD_DATA_DIR/books/<book-id>/page_<n>.jpg.
برای جدا کردن کتاب‌ها از دیتای کاربران یا پیش‌نمایش، ROSHD_BOOKS_DIR را روی پوشهٔ مادر کتاب‌ها تنظیم کنید.
اولویت: فایل داخل دیتای فعال؛ سپس ROSHD_BOOKS_DIR. اگر متغیر منابع تعریف نشده باشد، فقط دو کتاب داخلی hoosh_6 و hoosh_8_9 از data/books پروژه هم جستجو می‌شوند. کتاب سفارشی کانون دیگر به این مسیر برگشت نمی‌خورد. احراز هویت و کنترل مجوز کتاب قبل از خواندن فایل اجرا می‌شود.

فایل‌های data/books در گیت نیستند؛ در استقرار باید جداگانه منتقل شوند. تغییر کد نیازمند راه‌اندازی مجدد پردازش Node فعال است. دیتابیس واقعی نباید برای رفع تصویر seed یا reset شود.

بررسی محلی: ۵۳۷ تصویر کتاب ششم و ۵۴۰ تصویر کتاب هشتم/نهم موجود است؛ همه صفحات ارجاع‌شده در فهرست مباحث روی دیسک یافت شدند. مرورگر واقعی در محیط آزمایشی جدا برای مدیر و معلم، بازشدن تصاویر ابتدا و انتهای کتاب‌ها، تعویض کتاب، سبد آزمون و حالت خطا/تلاش مجدد را موفق بررسی کرد.

انتقال روی سرور: scripts/deploy_vps.py پس از git pull پوشه‌های data/books/hoosh_6 و hoosh_8_9 را با SFTP همگام می‌کند (فقط فایل‌های ناموجود یا متفاوت). مسیر مقصد با ROSHD_REMOTE_BOOKS_DIR و رد کردن مرحله با ROSHD_SYNC_BOOKS=0. اگر تصاویر روی دیسک نباشند، سرور هنگام شروع هشدار می‌دهد.

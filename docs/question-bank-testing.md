# راهنمای تست بانک سؤالات و موتور آزمون

## ۱. تست‌های خودکار
- `node scripts/test-question-bank.mjs`: تست جامع Unit + Integration + API End-to-End شامل:
  - ثبت دستی سؤال، کپی، ویرایش، نسخه‌گذاری و انتشار
  - بارگذاری و اعتبارسنجی JSON، ZIP و XLSX (شامل فایل معتبر، فایل دارای خطا، تصویر ناموجود، صفحه نامعتبر، بارگذاری مجدد و تشخیص سؤال تکراری)
  - امنیت ZIP (Zip Slip / Zip Bomb و پاکسازی SVG)
  - ساخت آزمون دانش‌آموز (از کل کتاب، یک صفحه، چند صفحه، کمبود سؤال، عدم افشای پاسخنامه در حین آزمون)
  - تصحیح خودکار (چهارگزینه‌ای، چندپاسخی، صحیح/غلط، عددی، جای‌خالی با نرمال‌سازی فارسی، وصل‌کردنی، مرتب‌سازی، ناحیه تصویر)
  - تصحیح تشریحی معلم و خودارزیابی دانش‌آموز
  - آزمون رسمی معلم، کارنامه، هدایت به صفحه مرجع کتاب و گزارش یادگیری صفحه‌محور
  - کنترل دسترسی نقش‌ها (دانش‌آموز بدون دسترسی به مدیریت بانک سؤال، محدودیت پایه/درس معلم، جداسازی مدارس)
- `node scripts/smoke.mjs`: تست دودی کل سامانه برای اطمینان از عدم اختلال در امکانات قبلی.
- `node scripts/review.mjs --base origin/main --quick`: بررسی نحو، امنیت و تست دودی.

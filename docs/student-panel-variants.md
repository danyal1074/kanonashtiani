# ساختارهای پنل دانش‌آموز

- انتخاب ساختار از نقش و پایه واقعی پاسخ `/api/me` در `public/js/student-variant.js` انجام می‌شود؛ پارامتر آدرس، نقش یا دسترسی API را عوض نمی‌کند.
- پایه‌های ۱ تا ۶: `public/js/elementary.js`، با CSS و تصاویر اصلی فایل ارسالی `roshd-student-panel.zip`؛ CSS مرجع به فضای دبستان محدود شده است.
- متوسطه: `public/js/student-design.js` و پوسته آبی فعلی.
- منطق آزمون، پیام‌رسان، پومودورو، پرداخت و خودسنجی اصلی برای هر دو ساختار حفظ شده است. داده‌های نمایشی زیپ وارد حساب‌ها نشده‌اند.
- مسیر سه‌بعدی زیپ در `public/js/elementary-world.js` با هشت سطح واقعی سازگار شده است. هنگام خروج از صفحه منابع WebGL آزاد می‌شوند؛ دستگاه بدون WebGL فهرست سطوح را می‌بیند.
- تصاویر اصلی در `public/img/elementary/` قرار دارند. شش آیکن جدید با ابزار داخلی ImageGen ساخته شده‌اند؛ فایل‌های `extra-*.webp` و پرامپت‌های دقیق در `extra-icons-prompts.json` ذخیره شده‌اند.
- `/api/student/attendance` فقط سوابق دانش‌آموز واردشده را برمی‌گرداند و قواعد نقش و قفل حق عضویت را رعایت می‌کند.
- ارسال تکلیف تنها با یادداشت، بدون پیوست، پشتیبانی می‌شود و فیلدهای فایل خالی به صورت NULL ذخیره می‌شوند.

## پیش‌نمایش محلی

- متوسطه: `student`، رمز نمونه `123456`

## اعتبارسنجی

`npm run smoke`: ۱۳۷ بررسی موفق، شامل انتخاب پایه، دسترسی حضور و غیاب و ارسال تکلیف متنی.
بررسی مرورگر: ۴۳ مورد موفق، شامل ۲۴ مسیر، هفت اندازه نمایش، ذخیره تکلیف، خروج از حساب، راه‌اندازی و آزادسازی WebGL، مسیر جایگزین بدون WebGL و جدایی پوسته‌ها.

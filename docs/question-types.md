# انواع سؤالات پشتیبانی‌شده در بانک سؤالات رشد

## ۱. انواع ۱۱گانه سؤال (`type`)
| کد نوع | عنوان فارسی | ساختار `answer` | تصحیح |
|---|---|---|---|
| `single_choice` | چهارگزینه‌ای تک‌پاسخی | `{ "correct_option_ids": ["c"] }` | خودکار |
| `multiple_choice` | چندگزینه‌ای چندپاسخی | `{ "correct_option_ids": ["a", "c"] }` | خودکار |
| `true_false` | صحیح و غلط | `{ "value": true }` | خودکار |
| `fill_blank` | جای خالی | `{ "accepted": ["پاسخ۱", "پاسخ۲"] }` | خودکار با نرمال‌سازی |
| `short_answer` | پاسخ کوتاه | `{ "accepted": ["پاسخ"] }` | خودکار با نرمال‌سازی |
| `descriptive` | تشریحی | `{ "model_answer": "...", "rubric": [{"criterion": "...", "points": 1}] }` | معلم (بارم‌بندی) / خودارزیابی |
| `numeric` | پاسخ عددی | `{ "value": 81, "tolerance": 0.01 }` | خودکار |
| `matching` | وصل‌کردنی | `{ "pairs": [{"left_id": "l1", "right_id": "r2"}] }` | خودکار |
| `ordering` | مرتب‌سازی | `{ "correct_order": ["i2", "i1", "i3"] }` | خودکار |
| `multipart` | چندبخشی | `{ "parts": [{"id": "p1", "type": "numeric", "answer": {...}, "score": 1}] }` | ترکیبی (خودکار/تشریحی) |
| `hotspot` | انتخاب نقطه/ناحیه تصویر | `{ "regions": [{"x": 50, "y": 40, "r": 12}] }` (درصد) | خودکار |

## ۲. ویژگی‌های محتوایی مستقل (`content_flags`)
هر سؤال علاوه بر `type` می‌تواند ویژگی‌های زیر را داشته باشد:
- `has_image`: تصویری
- `is_geometric`: هندسی
- `is_chart`: نموداری
- `has_table`: جدولی
- `has_formula`: دارای فرمول ریاضی (LaTeX با `$ ... $` یا `$$ ... $$`)

راهنمای نسخه نمایشی استاتیک رشد نخبه

این بسته برای نمایش امکانات به مدیر کانون ساخته شده و نیازی به Node.js، PHP یا دیتابیس ندارد.

نصب روی هاست اشتراکی:
۱. بهتر است یک زیردامنه اختصاصی مانند demo.example.com بسازید.
۲. محتویات فایل ZIP را در ریشه پوشه وب همان دامنه یا زیردامنه استخراج کنید؛ index.html باید مستقیماً در ریشه وب باشد.
۳. آدرس دامنه را باز کنید و پنل موردنظر را انتخاب کنید؛ رمز لازم نیست.
۴. برای تغییر نقش، از «تغییر پنل» در نوار بالای سایت استفاده کنید.

نکته: این بسته برای ریشه دامنه یا زیردامنه تنظیم شده است، نه یک زیرپوشه مانند example.com/demo/.
نکته: فایل index.html را با دوبارکلیک و file:// اجرا نکنید؛ سایت باید از طریق HTTP یا HTTPS باز شود.

ویژگی‌های نسخه دمو:
- داده‌های ساختگی و مستقل از اطلاعات نسخه اصلی
- ورود مستقیم به پنج پنل دانش‌آموز، معلم، مدیر، والدین و مدیر سامانه
- نمایش صفحه‌ها و گزارش‌ها با داده‌های ثابت نمونه
- ثبت‌نام، ذخیره تغییرات، آپلود، پرداخت و ارسال پیام واقعی غیرفعال
- فیلترهایی که به سرور وابسته‌اند، ممکن است همان داده نمونه را نشان دهند
- جزئیات بعضی رکوردها از نمونه‌های از پیش آماده نمایش داده می‌شود
- پیشرفت ذخیره‌شده واقعی یا ارتباط با سرور وجود ندارد

برای آپلود فقط محتویات همین بسته را بفرستید. پوشه‌های data و server و فایل‌های دیتابیس نسخه اصلی لازم نیستند.

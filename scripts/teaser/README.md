# تیزر «به‌زودی» برای دانش‌آموزان

تیزر عمودی (۹:۱۶، ۴۳ ثانیه) با تم شاد و رنگی برای کودکان. یه جعبه کادوی مرموز و ۷ «سرنخ» مبهم از امکانات پنل دانش‌آموز نشون می‌ده و آخرش جعبه باز می‌شه و «به‌زودی!» میاد.

| سرنخ | متن | اشاره به |
|---|---|---|
| ۰۱ | یه ساعت… که فقط برای تو می‌شمره | مطالعه و پومودورو |
| ۰۲ | یه مسیر… که خودش راه رو بلده | مسیر یادگیری هوشمند |
| ۰۳ | کلاسی که دیوار نداره | کلاس آنلاین |
| ۰۴ | قفسه‌ای که هیچ‌وقت بسته نمی‌شه | کتابخانه |
| ۰۵ | بازی؟ داستان؟ شاید هر دو… | بازی و داستان |
| ۰۶ | سکه‌هایی که ارزش جمع کردن دارن | سکه و فروشگاه کانون |
| ۰۷ | نقشه‌ای که نشون می‌ده چقدر بزرگ شدی | نقشه راه رشد |

## فایل‌ها
- `public/teaser.html`: نسخه‌ی تحت وب (آدرس `/teaser.html`)، با دکمه‌ی پخش و دانلود ویدیو
- `public/teaser/teaser.mp4`: ویدیوی آماده برای استوری/واتساپ/کانال (۱۰۸۰×۱۹۲۰)
- `public/teaser/teaser-music.mp3`: موسیقی (کاملاً ساخته‌شده با کد، بدون مشکل کپی‌رایت)

## ساخت دوباره
```bash
python3 scripts/teaser/make-music.py /tmp/music.wav
ffmpeg -y -i /tmp/music.wav -b:a 192k public/teaser/teaser-music.mp3
python3 -m http.server 8765 -d public &
node scripts/teaser/render-video.cjs http://localhost:8765/teaser.html public/teaser/teaser.mp4
```
متن‌ها در آرایه‌ی `HINTS` و تابع‌های `scene*` داخل `public/teaser.html` هستند.

# تیزر دوم: «دفترچه‌ی راز» (۳۸ ثانیه)

ظاهر کاملاً متفاوت: کاغذ دفتر خط‌دار، نقاشی‌هایی که با مداد کشیده می‌شن، رنگ‌آمیزی با مداد شمعی، کاغذ یادداشت و چسب، ورق خوردن صفحه‌ها.
به‌جای «سرنخ»، ۵ «چیستان» می‌پرسه که جوابشون گفته نمی‌شه. آخرش قفل باز می‌شه و «به‌زودی!» میاد.

| چیستان | متن | اشاره به |
|---|---|---|
| ۱ | چیه که هم کلاسه… هم تو خونه‌ست؟ | کلاس آنلاین |
| ۲ | چیه که قصه می‌گه، بازی می‌کنه… ولی آدم نیست؟ | بازی و داستان |
| ۳ | چیه که هر بار تلاش کنی، جیبت پرتر می‌شه؟ | سکه و فروشگاه |
| ۴ | چیه که می‌دونه فردا باید چی بخونی؟ | برنامه و مسیر یادگیری |
| ۵ | چیه که پر از کتابه… ولی تو جیبت جا می‌شه؟ | کتابخانه |

موسیقی: پیتزیکاتوی یواشکی، بعد ماریمبا و سوت شاد، صدای مداد و ورق (`scripts/teaser/make-music-2.py`).

- `public/teaser2.html`: نسخه‌ی وب (`/teaser2.html`)
- `public/teaser2/teaser.mp4` و `public/teaser2/teaser-music.mp3`

```bash
python3 scripts/teaser/make-music-2.py /tmp/music2.wav

node scripts/teaser/render-video.cjs http://localhost:8765/teaser2.html public/teaser2/teaser.mp4
```

# تیزر سوم: «ماجراجویی بزرگ» (۳۸ ثانیه)

ظاهر بازی‌های قدیمی پیکسلی (۸-بیتی): یه دانش‌آموز کوله‌به‌دوش تو مرحله می‌دوه، می‌پره، به جعبه‌های «؟» می‌زنه و ۵ آیتم جمع می‌کنه. آیتم‌ها در مخفی رو باز می‌کنن و «به‌زودی! مرحله‌ی جدید» میاد. موسیقی چیپ‌تیون با صدای سکه، پرش و پاورآپ.

| آیتم | جایزه | اشاره به |

| سکه‌ی طلایی | +۵۰ امتیاز | سکه و فروشگاه |
| نقشه‌ی گنج | مسیر مخفی باز شد! | مسیر یادگیری / نقشه راه |
| جام قهرمانی | +۱۰۰ افتخار | کارنامه و نتایج |

- `public/teaser3.html` (`/teaser3.html`)، `public/teaser3/teaser.mp4`، `public/teaser3/teaser-music.mp3`

# تیزر چهارم: «قهرمان‌های کانون» (۴۳ ثانیه)

سبک کتاب‌های کمیک ابرقهرمانی: قاب‌های کمیک با خط دور مشکی، نقطه‌های هافتون، خطوط سرعت، حباب گفتگو و افکت‌هایی مثل «پاو!» و «بوم!». یه دانش‌آموز شنل‌پوش قهرمان اصلیه.
این نسخه برخلاف قبلی‌ها **اسم امکانات رو صریح می‌گه**: «۸ قدرت جدید».

| قدرت | اسم | جمله |
|---|---|---|
| ۱ | پومودورو | تایمر تمرکز + رقابت هفتگی! |
| ۲ | بازی درسی «ذهن سریع» | سریع جواب بده، امتیاز ببر! |
| ۳ | داستان تعاملی «راز رصدخانه» | داستان رو خودت جلو ببر! |
| ۴ | آواتار من | قهرمانت رو خودت بساز! |
| ۵ | نشان‌های من | با ۵۰ امتیاز، جایزه‌ی روزانه! |
| ۶ | مسیر یادگیری هوشمند | خودش می‌گه امروز چی بخونی! |
| ۷ | کلاس آنلاین | هرجا باشی، کلاس با توئه! |
| ۸ | کارنامه و رتبه | رتبه‌ت تو پایه رو ببین! |

بعد «و تازه…»: کتابخانه، تکالیف، آزمون خودسنجی، مشاور تحصیلی، فروشگاه کانون، برنامه هفتگی، تولدت مبارک! و آخرش «به‌زودی! پنل جدید دانش‌آموزان».
موسیقی: سرود حماسی ابرقهرمانی با برنج، تیمپانی و افکت ووش (`scripts/teaser/make-music-4.py`).

- `public/teaser4.html` (`/teaser4.html`)، `public/teaser4/teaser.mp4`، `public/teaser4/teaser-music.mp3`

# تیزر پنجم: «رونمایی» (۴۲ ثانیه، رسمی)

سبک رسمی و مینیمال (مثل اعلام رونمایی محصول): زمینه‌ی کرم روشن، سرمه‌ای و طلایی، تایپوگرافی ظریف، خطوط نازک هندسی، حرکت آرام و یک قاب دیجیتال مات‌شده.
متن‌ها به فارسی رسمی:

- «کانون نخبه‌پروری شهید کاظم آشتیانی تقدیم می‌کند»
- «هر تحولی با یک پرسش آغاز می‌شود.» / «اگر یادگیری… شکل دیگری داشت؟»
- پنج واژه با نقش‌مایه‌ی هندسی: هوشمندتر. (شبکه) / شخصی‌تر. (نقطه‌ی متمایز) / منسجم‌تر. (چیدمان مربع‌ها) / در دسترس‌تر. (امواج) / الهام‌بخش‌تر. (منحنی رشد)
- قاب پوشیده: «طراحی‌شده برای دانش‌آموزان کانون» / «یک تجربه‌ی تازه.»
- «به‌زودی، رونمایی می‌شود. منتظر باشید.»

موسیقی سینمایی: پیانو، زهی‌ها، پالس آرام، اوج و ضربه‌ی پایانی (`scripts/teaser/make-music-5.py`).

- `public/teaser5.html` (`/teaser5.html`)، `public/teaser5/teaser.mp4`، `public/teaser5/teaser-music.mp3`

# تیزر ششم: «سرآغاز» (۳۸ ثانیه، افقی ۱۶:۹)

- «دانش، بازی و داستان / در هم می‌آمیزند» (بازی و داستان)

# تیزر هفتم: «آغاز تازه» (۳۹ ثانیه، افقی، رسمی، با گویندگی)

سبک سینمایی با رنگ‌های سازمانی (سبزآبی تا سرمه‌ای، طلایی)، نوار سینمایی بالا و پایین، تایپوگرافی بزرگ هم‌زمان با گوینده، گوشی با اسکرین‌شات واقعی پنل.
**متن گوینده و زمان‌بندی در `public/teaser7/script.json` است**؛ صفحه، ساخت صدا و میکس همه از همین فایل می‌خوانند.

ساخت نسخه‌ی گویندگی‌شده:
```bash
python3 scripts/teaser/make-music-7.py /tmp/music7.wav
# الف) صدای ماشینی آفلاین (Piper، مدل فارسی fa_IR-*.onnx لازم است):
python3 scripts/teaser/make-voice.py fa_IR-gyro-medium.onnx /tmp/vo
# ب) یا گوینده‌ی انسانی: هر خط را جدا ضبط کنید و با نام l01.wav … l12.wav در /tmp/vo بگذارید
python3 scripts/teaser/mix-voice.py /tmp/music7.wav /tmp/vo public/teaser7/teaser-audio.mp3
node scripts/teaser/render-video.cjs http://localhost:8765/teaser7.html public/teaser7/teaser.mp4 public/teaser7/teaser-audio.mp3
```
